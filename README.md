# GoaliasOS

> **一个以“个人成长”为核心的操作系统式生活管理服务平台**

在这里，目标是进程，习惯是服务，反思是日志，成长是不断迭代的内核。

## 核心思想：数字孪生

GoaliasOS 创新性地将 **数字孪生（Digital Twin）** 概念引入个人成长管理领域，构建了一个与现实自我平行的数字化镜像系统。

### 操作系统隐喻映射
| 现实概念 | 操作系统映射 | 说明 |
|---------|------------|------|
| **个人目标** | 进程（Process） | 可启动、暂停、终止的执行单元，支持多目标并行管理 |
| **日常习惯** | 服务（Service） | 后台持续运行的守护进程，自动化习惯养成 |
| **成长反思** | 日志（Log） | 记录系统运行状态和关键事件，支持回溯分析 |
| **自我迭代** | 内核更新（Kernel Update） | 持续优化的核心系统，实现版本化成长 |

### 数字孪生运作机制
```
┌─────────────────┐    数据采集     ┌─────────────────┐
│   现实自我       │ ──────────────→ │   GoaliasOS     │
│   (Physical)    │                 │   (Digital)     │
└─────────────────┘                 └─────────────────┘
         ↑                                   │
         │          智能分析与反馈             │
         └───────────────────────────────────┘
```

- **实时同步**：目标进度、习惯打卡、反思记录实时映射到数字系统
- **智能分析**：AI 驱动的行为模式识别与成长建议生成
- **预测模拟**：基于历史数据预测目标达成概率和习惯养成周期
- **闭环优化**：数字世界的洞察反哺现实行动，形成持续改进循环

## 项目亮点

### 1. 操作系统式架构设计
- 采用分层架构设计，严格遵循领域驱动设计原则
- 模块化组件封装，支持灵活扩展和独立部署
- 统一异常处理和日志规范，确保系统稳定性

### 2. AI 驱动的智能增强
- **Spring AI + LangChain4j** 双框架集成，提供强大的 AI 能力
- 支持通义千问等多种大语言模型接入
- AI Function Calling 工具扩展，实现智能交互
- 知识库 RAG 功能规划中，支持个性化知识管理

### 3. 企业级安全与可靠性
- **Sa-Token** 权限认证框架，支持 JWT、Redis 会话管理
- 统一参数验证和 XSS 防护，保障系统安全
- Redis 分布式缓存 + 限流熔断机制，确保高可用
- 敏感字段自动脱敏，符合数据安全规范

### 4. 现代化技术栈
- **Spring Boot 3.4.4** + **Java 17**
- **MyBatis-Plus** ORM 框架，简化数据访问层开发
- **MinIO** 对象存储，支持文件、图片、附件管理
- **阿里云短信/邮件** 通知服务，多渠道消息触达

## 开发指南

### 新增业务功能
1. **定义领域模型**：在 `os-service` 对应模块创建实体类
2. **创建数据访问层**：使用 MyBatis-Plus 创建 Mapper
3. **定义服务接口**：在 `os-service` 模块定义业务接口
4. **实现业务逻辑**：在 `os-web` 模块实现服务接口
5. **创建控制器**：在 `os-web` 模块创建 REST API

### 新增 AI 功能
1. **定义工具接口**：在 `common-chat` 模块定义 Function Calling 接口
2. **实现工具逻辑**：编写工具函数的具体实现
3. **测试工具调用**：通过 AI 对话测试工具是否正常工作
4. **优化提示词**：调整函数描述，提高 AI 调用准确性

### 代码规范
- 遵循分层架构约束，业务逻辑与接口分离
- 复用 `os-common` 中的工具类和服务
- 所有 API 需要权限校验（除公开接口）
- 用户输入必须经过 XSS 过滤和参数验证
- 敏感字段使用 `@Sensitive` 注解自动脱敏
- 代码注释使用中文，清晰说明业务逻辑
